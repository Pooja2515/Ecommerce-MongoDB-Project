# E-commerce Database Management System using MongoDB

## Project Overview
This project demonstrates how MongoDB can be used to manage an e-commerce database. It stores product and order information and performs database operations and sales analysis.

## Objectives
- Manage products and orders using MongoDB.
- Perform CRUD operations.
- Search and filter products using query operators.
- Generate revenue reports using aggregation pipelines.
- Improve query performance using indexes.

## Technologies Used
- MongoDB
- MongoDB Shell (mongosh)
- MongoDB Compass
- Visual Studio Code

## Database Structure
**Database:** `ecommerce`

**Collections:**
- `products` — stores product names, categories, prices, and stock.
- `orders` — stores order IDs, products, quantities, prices, and months.

## Project Features
1. Insert, retrieve, update, and delete product records.
2. Search products by category, price, and stock.
3. Sort and limit query results.
4. Calculate total revenue and revenue by product.
5. Generate monthly revenue reports.
6. Create and inspect indexes.

## Project Files
- `01_create_database.js` — creates sample product records.
- `02_crud_operations.js` — demonstrates CRUD operations.
- `03_queries_and_filters.js` — demonstrates filtering and sorting.
- `04_aggregation_reports.js` — generates sales and revenue reports.
- `05_indexes.js` — creates and displays indexes.
